# 2-Minute SIH Demo

1. Open JAL-DRISHTI and select **Heavy** rainfall.
2. Click **Run / Recalculate Scenario**.
3. Point to red/orange roads and explain that they are scenario-ranked vulnerability, not official warnings.
4. Select an evacuation origin and destination.
5. Explain that the blue route minimizes a risk-aware cost after closed roads are removed.
6. Compare its distance and modeled risk with the shortest-distance route.
7. Show the emergency response table: simulated incidents are matched to available units using risk-aware routes.
8. Switch to **Extreme** rainfall and rerun.
9. Show that the scenario changes road risk, closures and potentially the selected route.
10. Close with: "The production path is validated DEM/drainage/historical-event calibration and authoritative live data integration."
